# 📝 Task Planner (Kanban Board)

A full-stack Kanban task management application built with React, Express.js, and MySQL via Prisma ORM.

## 🚀 Tech Stack
- **Frontend:** React (Vite), Tailwind CSS v4, Axios, Lucide Icons
- **Backend:** Node.js, Express.js, Prisma ORM (v6)
- **Database:** MySQL

## 🛠️ Getting Started

### Backend Setup
1. `cd server`
2. `npm install`
3. Configure `.env` with your MySQL `DATABASE_URL`
4. `npx prisma migrate dev`
5. `npm run dev`

### Frontend Setup
1. `cd client`
2. `npm install`
3. `npm run dev`
